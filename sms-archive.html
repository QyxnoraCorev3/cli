📨 SMS Archive Viewer Guide

Prefix Search Requirement:

Search strictly matches the beginning of the NAME field using case-insensitive startsWith(). For example:

  • Typing "Xia" matches Xiaomi.
  • Typing "ia" will not match Xiaomi.
  • Typing "Go" matches GoDaddy, Google, GooChat.

Keyboard Shortcuts:

  • / : Focus search box instantly from anywhere
  • Escape : Clear search and close dialogs
  • Enter : Jump to first card when searching

Data Import Support:

  • Import TXT: Select your text file formatted with NAME : ..., MESSAGE : ..., Country: ...
  • Import JSON: Select a valid JSON array of SMS objects.
  • Load Attached: Instantly loads all 12,675+ records bundled with this project.
  • Local & Safe: 100% in-browser processing. Zero data uploaded to any server.
